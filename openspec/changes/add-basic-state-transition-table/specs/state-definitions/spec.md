# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-002 - 不正な状態定義の報告

IF 状態宣言の構文、ID、状態名、カラー、意味のインデントや内容がREQ-001の範囲を外れる、IDが重複する、または状態定義、REQ-007のイベント、REQ-008の遷移のいずれにも属さない記述がある場合、THEN DSL解析機能は、該当行と理由を持つエラーを返し、その文書の状態定義を正常な結果として返してはならない(SHALL)。\
意味の非空行は半角空白4個だけでインデントし、タブやそれ以外の深さを許可しない。\
IDは大文字と小文字を区別して重複を判定し、必須の宣言要素や意味を省略できない。

#### Scenario: REQ-002-S01 - 不正な入力の位置と理由を返す

- **GIVEN** 正常な状態定義のうち、次の箇所だけを不正にした内容がある。

  | 不正な箇所 | 入力例 | エラーの対象 |
  | --- | --- | --- |
  | 宣言の要素不足 | `as "待機"`を省略 | 宣言行の構文 |
  | 宣言末尾 | `:`を省略 | 宣言行の構文 |
  | ID | `1IDLE` | 宣言行のID |
  | 状態名 | `""`、`"   "` | 宣言行の状態名 |
  | 状態名の引用符 | 閉じる`"`を省略 | 宣言行の構文 |
  | 状態名の改行 | 引用符を閉じる前に改行 | 宣言行の構文 |
  | 状態名の途中の引用符 | 名前の途中に`"`を入れる | 宣言行の構文 |
  | カラー | `"red"`、`"#FFF"`、`"#GG0000"` | 宣言行のカラー |
  | カラーの不足 | `color "#4F46E5"`を省略 | 宣言行の構文 |
  | 意味の不足 | 宣言直後が文書末尾 | 意味を欠く宣言行 |
  | 意味の内容 | 意味を空白だけにする | 意味を欠く宣言行 |
  | 意味のインデント | 半角空白2個、8個、タブ1個 | 意味の行のインデント |
  | 未対応の記述 | 独立した`Group STATES`の行 | 未対応の行 |

- **WHEN** 各内容を解析する。
- **THEN** 表の対象行を指すエラーと、構文、ID、状態名、カラー、意味、インデント、未対応の記述のうち該当する理由が返る。
- **AND** 正常な状態定義の結果は返らない。

#### Scenario: REQ-002-S02 - 重複したIDを報告する

- **GIVEN** 2件の状態のIDがともに`IDLE`である。
- **WHEN** 内容を解析する。
- **THEN** 2件目の宣言行にIDの重複を示すエラーが返る。
- **AND** 正常な状態定義の結果は返らない。

#### Scenario: REQ-002-S03 - IDの大文字と小文字を区別する

- **GIVEN** 2件の状態のIDが`IDLE`と`idle`である。
- **WHEN** 内容を解析する。
- **THEN** 状態は2件で、それぞれのIDが保持され、重複エラーはない。
