# 仕様書の一覧

各仕様書の役割と関係を示す。\
要件の内容は各仕様書を正とし、ここには書かない。

## 一覧

| capability | 扱う内容 |
| --- | --- |
| state-definitions | `.gls`による状態と状態グループの記法、所属と定義順、解析結果、受け付ける宣言と不正入力の報告 |
| state-transitions | `.gls`によるイベントと分類経路、文書単位の分類列見出し、共通処理と条件ごとの処理と遷移先、参照と重複の検証 |
| state-definition-preview | VS Codeでの状態定義表、対象文書、保存前の更新、診断と正常な表の保持、状態の単一選択と文書とIDによる保持と解除 |
| state-transition-diagram | 状態名とカラーのノード、状態グループの実線枠、共通の外部到達先への矢印集約、全分岐先を反映する淡い矢印、自己ループ、選択状態ノードの背景強調、拡大と縮小と中心を保つ等倍Reset、同一文書の表示範囲の継続、選択強調を除き現在のテーマで図全体をPNGとSVGへ保存する操作、図と両方の表の整合 |
| state-transition-table | イベントと状態を軸とする表、分類と個別の列見出し、共通処理の下だけの分岐表示、分岐なしの処理と遷移先、未定義、グループによらない個別セルの保持、選択状態列全体の背景強調、3表示の更新 |

## 関係と読む順番

`state-definitions`で状態とグループの入力と所属、解析結果、受け付ける宣言を確認し、`state-transitions`でイベントの分類と列見出し、分岐なしと共通処理を持つ分岐遷移の記法と参照を確認する。\
`state-definition-preview`でプレビューの対象と状態定義表、`state-transition-table`で共通処理と分岐のセル、分類付きの表と3表示の整合を読む。\
`state-transition-diagram`で全分岐先を含む状態間の図、グループ枠と外部到達先への集約、3表示の整合を読む。\
状態定義表、状態遷移図、状態遷移表は、同じ文書の解析結果から生成する。

状態定義表で選んだ状態は、同じ文書の状態IDで3表示へ対応付ける。\
選択の操作と寿命は`state-definition-preview`、状態ノードの強調は`state-transition-diagram`、状態列全体の強調は`state-transition-table`を読む。
