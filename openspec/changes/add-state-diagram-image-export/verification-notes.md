# 実装と検証の記録

## 保存する内容

保存操作はGlitchFlowと同じ`⇩`からPNGとSVGの形式選択、保存先選択へ進む。\
現在表示できる図全体を対象とし、状態の選択強調を除外して、通常の背景と現在のテーマの不透明背景を保存する。\
Webviewは現在のDOMの配置、名前の行と矢印から単独SVGを生成し、そのSVGからPNGを作る。\
Extensionは要求と現在の通知を照合して、保存先へ画像のバイト列を書き込む。
