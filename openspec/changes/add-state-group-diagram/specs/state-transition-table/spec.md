# 差分仕様

## ADDED Requirements

### Requirement: REQ-032 - グループ化によらない個々の状態と遷移の保持

WHEN 状態グループを持つ文書をプレビューするとき、状態定義表と状態遷移表は、グループ宣言だけを除いた同じ文書と同じ状態、イベント、遷移を表示しなければならない(SHALL)。\
グループを表の行や列にせず、状態の定義順とIDによる交点、状態名とカラー、分類と独立した見出し、分岐なしの2段と共通処理の下だけの分岐表示を維持する。\
図で集約した場合も元の各状態とイベントの処理と遷移先は別々のセルに保持し、遷移のないメンバーへ共通到達先を補わず、なしと未定義を区別する。\
遷移定義や状態とイベントの配列をグループ単位へ置換しない。

#### Scenario: REQ-032-S01 - 図の集約後も個別のセルと未定義を保つ

- **GIVEN** GにA、B、Cが所属し、AのSTARTには固有の処理とXへの分岐なし遷移、BのRETRYには固有の共通処理とXへの分岐があり、Cには遷移を定義していない。
- **WHEN** グループ付き文書と、グループ宣言だけを除いた文書を表示する。
- **THEN** 両文書の両表は全状態とイベントの数、順序、名前とカラー、各交点の全内容が一致し、グループの行や列はない。
- **AND** グループ付きの図でGからXへ1本に集約されても、AとBの異なる処理と分岐は元の交点にだけあり、Cのセルは赤文字の未定義のままである。

#### Scenario: REQ-032-S02 - 分類と分岐と状態の定義順を保持する

- **GIVEN** 状態はA、未所属U、Bの順で、Gの所属順はB、Aであり、分類なしと3段分類が混在し、指定した列見出しと、なしを持つ分岐なしと分岐付きセルがある。
- **WHEN** グループ付き文書を表示する。
- **THEN** 状態定義表の状態順と状態遷移表の状態列はA、U、Bのままで、分類の結合と不足段の空欄、見出し、全交点の条件と処理と遷移先、なしと未定義はグループなしの文書と一致する。
