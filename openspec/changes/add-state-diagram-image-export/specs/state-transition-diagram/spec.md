# 差分仕様

## ADDED Requirements

### Requirement: REQ-041 - PNGとSVGの保存操作

WHEN 表示準備が完了した状態遷移図を保存するとき、プレビューは、REQ-038の操作部の`⇩`からPNGとSVGの形式選択、保存先の選択の順に進み、選んだ形式の画像を指定先へ保存しなければならない(SHALL)。\
ボタンの表示文字は`⇩`、読み上げ名とツールチップは`図をエクスポート`とし、マウスとキーボードで操作可能にする。\
初期の保存先は対象の`.gls`と同じ場所、同じ基底名、選んだ形式の拡張子とし、形式に対応するファイルフィルターを使う。\
図がない場合は操作部を表示せず、計測中と保存処理中は保存操作を受け付けない。\
形式または保存先の選択をキャンセルした場合は書き込まず、成功や失敗として通知しない。

#### Scenario: REQ-041-S01 - 選択した形式と保存先で画像を保存する

- **GIVEN** `design.gls`の表示可能な図がある。
- **WHEN** 保存操作を起動し、次の形式と保存先を選ぶ。

  | 形式 | 初期ファイル名 | 保存先のフィルター | 保存結果 |
  | --- | --- | --- | --- |
  | PNG | design.png | png | 指定先にPNGとして開ける画像1件 |
  | SVG | design.svg | svg | 指定先にSVGとして開ける画像1件 |

- **THEN** 形式選択にはPNGとSVGがこの順で並び、保存先の初期位置は`design.gls`と同じ場所で、保存結果は表の内容と一致する。
- **AND** 保存先ダイアログの保存操作は`図を保存`である。

#### Scenario: REQ-041-S02 - キーボードで保存操作を起動する

- **GIVEN** 図の保存ボタンが有効である。
- **WHEN** Tabで保存ボタンへ移り、EnterまたはSpaceで起動する。
- **THEN** フォーカス位置を読み取れ、フォーカスだけでは保存を始めず、起動1回につき形式選択を1回だけ開く。
- **AND** ボタンの表示文字は`⇩`で、読み上げ名とツールチップは`図をエクスポート`である。

#### Scenario: REQ-041-S03 - 図がない場合と計測中に保存しない

- **GIVEN** 次のいずれかの内容を表示している。

  | 内容 | 保存操作 |
  | --- | --- |
  | 状態0件 | 操作部がない |
  | 正常表示のない解析エラー | 操作部がない |
  | 図の状態名とグループ枠の計測中 | 保存ボタンを起動できない |

- **WHEN** 保存操作を試みる。
- **THEN** 表の状態となり、形式選択と保存先選択は開かず、画像生成と書き込みは行わない。
- **AND** 計測中の図は、準備が完了した後に保存できる。

#### Scenario: REQ-041-S04 - 保存中の重複操作を受け付けない

- **GIVEN** 1件の保存で形式選択、保存先選択、画像生成、または書き込みが進んでいる。
- **WHEN** 保存ボタンを再び起動しようとする。
- **THEN** 進行中の保存だけが続き、追加のダイアログ、画像生成と書き込みは発生しない。
- **AND** 処理が終われば現在の図の準備状態に従って保存操作を再び受け付ける。

#### Scenario: REQ-041-S05 - キャンセルしてファイルを作らない

- **GIVEN** 図の保存操作を起動している。
- **WHEN** 形式選択または保存先選択をキャンセルする。
- **THEN** 画像ファイルの作成と上書き、保存成功と保存失敗の通知はなく、再び保存操作を起動できる。

### Requirement: REQ-042 - 選択強調を含まない図全体の画像

WHEN 状態遷移図をPNGまたはSVGで保存するとき、画像は、現在の倍率と表示位置に依存せず、図全体を欠落なく含まなければならない(SHALL)。\
全状態の名前と指定カラー、通常のノード背景、グループの実線枠と名前、個別と集約の矢印、自己ループと各終端へ向く矢尻を、表示中の関係と配置で保つ。\
状態の選択強調を含めず、現在のテーマの不透明背景と文字、枠、淡い矢印の配色を使う。\
両表、見出し、操作部、倍率と案内、操作用の接続点は含めない。\
SVGは外部の資源に依存しないベクター画像、PNGは同じ図の画像として単独で開ける形式とし、名前の文字列を実行可能な内容として扱わない。

#### Scenario: REQ-042-S01 - 画面外も含む全体とすべての矢印を保存する

- **GIVEN** 画面外に状態とグループ枠があり、個別矢印、分岐先への矢印、グループからの集約矢印、自己ループと相互遷移がある図を拡大して移動している。
- **WHEN** 図を保存する。
- **THEN** 画像には全状態と全グループの名前、枠とノードの全領域、実際の図と同じ有向ペアの全矢印があり、経路と矢尻は画像の境界で切れない。
- **AND** 通常の矢印、集約矢印、自己ループと相互遷移の各矢尻は、画像内の経路終端の進行方向と一致する。
- **AND** 別の倍率と位置で同じ図を保存しても、図全体の範囲と画像内の配置は変わらない。

#### Scenario: REQ-042-S02 - 選択強調と操作UIを画像に含めない

- **GIVEN** 状態Aを選択しており、Aだけのノード背景を強調し、両表と図の見出し、操作部、倍率と案内を表示している。
- **WHEN** 図を保存する。
- **THEN** 画像のAは通常のノード背景であり、未選択時に保存した同じ図と一致する。
- **AND** 画像には状態名とグループ名だけがあり、両表とその内容、見出し、操作ボタン、倍率、案内と接続点はない。

#### Scenario: REQ-042-S03 - 明暗テーマの不透明背景と配色を保存する

- **GIVEN** 指定カラーを持つ状態、枠と名前、矢印と矢尻を含む図を表示している。
- **WHEN** 明テーマまたは暗テーマで保存する。
- **THEN** 画像の背景は保存対象のテーマの背景色で全域が不透明であり、状態名の指定カラー、通常のノード背景、枠と名前、淡い矢印と矢尻の配色はそのテーマの図と一致する。
- **AND** 白背景や透明背景へ一律に置き換わらない。

#### Scenario: REQ-042-S04 - 単独のSVGで文字とベクターの図形を保つ

- **GIVEN** 日本語、改行、`<b>待機</b>`と`A&B`を含む名前のノードとグループがある。
- **WHEN** SVGで保存し、プレビューから独立して開く。
- **THEN** SVGとして読み取れ、名前の文字列と行の並び、図の文字と図形を保持し、外部のスタイルや画像、スクリプトの読み込みを必要としない。
- **AND** 図全体を埋め込みのラスター画像へ置き換えず、名前からb要素や実行可能な要素は作られない。

#### Scenario: REQ-042-S05 - PNGを実際の画像として開ける

- **GIVEN** 異なる状態カラー、グループ枠、通常の矢印と自己ループを持つ図がある。
- **WHEN** PNGで保存し、プレビューから独立して開く。
- **THEN** 正の幅と高さを持つPNGとして読み取れ、状態と枠、名前、矢印と矢尻がSVGと同じ関係と配置で描かれ、空の画像や背景だけの画像ではない。

#### Scenario: REQ-042-S06 - 長い名前と自己ループを省略しない

- **GIVEN** 複数行に折り返した状態名とグループ名、枠の上へ張り出す自己ループがある。
- **WHEN** 図を保存する。
- **THEN** 各名前の末尾と行の並び、状態と枠の全領域、自己ループの経路と矢尻が画像内にあり、省略やクリップ、名前とノードの重なりを追加しない。

#### Scenario: REQ-042-S07 - 矢印のない状態も保存する

- **GIVEN** 有効な状態があり、イベントと遷移はない。
- **WHEN** 図を保存する。
- **THEN** 全状態の名前、カラーと通常の背景を持つ画像となり、矢印がないことを理由に拒否したり、矢印を追加したりしない。

### Requirement: REQ-043 - 保存対象と非同期の結果の整合

WHEN 図の保存を進めるとき、プレビューは、対象文書と表示済みの内容を照合し、受理した1件の保存要求に対応する画像だけを保存しなければならない(SHALL)。\
未保存の現在の表示を対象とし、解析エラーで保持した正常な図もその表示内容で保存する。\
形式選択から書き込み開始までに対象文書や内容が更新された場合は書き込まず、再操作を案内する。\
古い要求、不正な応答、閉じたプレビューの応答は保存に使わない。\
生成不能、応答不能、保存先の拡張子不一致と書き込み失敗を通知し、再操作可能にする。\
保存の起動、完了、キャンセルと失敗は、DSL、診断、3表示と状態選択、図の倍率と位置を変更せず、追加の描画完了通知を発生させない。

#### Scenario: REQ-043-S01 - 未保存の現在の図とエラー保持からの回復を保存する

- **GIVEN** 保存済みの内容とは異なる名前と遷移先を未保存で表示し、その後参照エラーとなって正常な図を保持している。
- **WHEN** 保持中に保存し、さらに名前と遷移先を以前と異なる有効な内容へ修正して再び保存する。
- **THEN** 最初の画像は保持中の図、修正後の画像は現在の異なる名前と矢印の終点を含み、保存済みの古いDSLから画像を作り直さない。
- **AND** エラー案内はどちらの画像にも含めない。

#### Scenario: REQ-043-S02 - 保存中の文書と内容の変更を取り違えない

- **GIVEN** 表示中の図の形式または保存先を選んでいる、またはその図の画像を生成している。
- **WHEN** 同一文書の内容が更新される、または別文書へ切り替わる。
- **THEN** 進行中の要求ではファイルを書き込まず、図が更新されたため再操作が必要なことを案内する。
- **AND** 再操作した場合は現在の文書と表示内容で保存する。

#### Scenario: REQ-043-S03 - 古い要求と不正な画像の応答を保存しない

- **GIVEN** 現在の文書の保存要求があり、次のいずれかの応答が届く。

  | 項目 | 応答の不正な内容 |
  | --- | --- |
  | 保存要求 | 以前の要求の識別子、別文書、異なる表示の内容 |
  | 画像の形式 | 要求と異なる形式、未対応の形式 |
  | 画像の内容 | 欠落、型違い、空、宣言形式と異なるデータ |

- **WHEN** 応答を受信する。
- **THEN** その応答では書き込まず、無関係な応答で現在の要求を完了させず、不正な現在の結果は保存失敗として扱う。

#### Scenario: REQ-043-S04 - 失敗後に再び保存できる

- **GIVEN** 保存操作中に、画像生成の失敗、設定した待機時間までの応答欠落、送信失敗、保存先の形式と異なる拡張子、または書き込み失敗が発生する。
- **WHEN** 保存処理の結果を確定する。
- **THEN** 保存できなかった理由を通知し、成功として扱わず、次の保存操作を受け付ける。
- **AND** 画像を生成できなかった場合と保存先の拡張子が一致しない場合は、書き込みを始めない。

#### Scenario: REQ-043-S05 - プレビューを閉じた後の結果で保存しない

- **GIVEN** 画像の保存先を選択中、または生成応答を待っている。
- **WHEN** プレビューを閉じてから以前の応答が届く。
- **THEN** 以前の要求の書き込みはなく、待機を終了し、新しいプレビューの保存要求と取り違えない。

#### Scenario: REQ-043-S06 - 保存操作で表示と編集状態を変えない

- **GIVEN** 診断とエラー保持中の図、状態Aの選択、操作後の倍率と位置がある。
- **WHEN** 保存操作を成功、キャンセル、または失敗で終える。
- **THEN** DSLの内容と未保存状態、診断、図と両表の内容と寸法、Aの選択、倍率と位置は開始前と一致する。
- **AND** 保存操作だけによる追加の描画完了通知はない。

## MODIFIED Requirements

### Requirement: REQ-030 - 所属状態を囲む名前付きの実線枠

WHEN 有効な状態グループをプレビューするとき、状態遷移図は、グループ名を持つ実線の枠で所属する状態ノードだけを囲み、個々の状態名と指定カラーを保持しなければならない(SHALL)。\
同名の状態とグループはIDで区別し、未所属状態はどの枠にも含めず、各グループと未所属状態の領域を重ねない。\
所属状態は状態の定義順に配置し、枠内に名前と状態、内部の自己ループを欠落なく収め、グループ名は表示用テキストとして扱う。\
状態定義表と状態遷移表の間という配置とテーマに沿う表示を保ち、グループ宣言がなければ既存の図を維持する。\
表示範囲はREQ-040、状態定義表からの状態選択の表示はREQ-036に従い、図からの状態選択とグループ選択は追加せず、操作部はREQ-038の縮小、Reset、拡大とREQ-041の画像保存に従う。

#### Scenario: REQ-030-S01 - 指定した状態だけを実線の枠で囲む

- **GIVEN** 定義順が`A`、未所属`X`、`B`、`C`の状態があり、グループ`G`(稼働系)の所属は`C`、`A`、`B`の順で指定している。
- **WHEN** 図を表示する。
- **THEN** `稼働系`の実線枠は1つで、内部の状態は定義順の`A`、`B`、`C`の各1件であり、それぞれの名前と指定カラーが保たれる。
- **AND** `X`は枠外にあり、枠は状態定義表と状態遷移表の間にだけ表示される。

#### Scenario: REQ-030-S02 - 同名グループと名前の文字列を区別する

- **GIVEN** 異なるIDのグループ2件が同じ名前`<b>稼働系</b>`で、それぞれの所属状態は異なり、同名状態もある。
- **WHEN** 図を表示する。
- **THEN** 同名グループの実線枠は2つで重ならず、状態の統合と混入はなく、グループ名の文字列は各枠にそのまま表示され、b要素は作られない。

#### Scenario: REQ-030-S03 - 長い名前と実測した状態とループを枠に収める

- **GIVEN** 折り返しが必要な長いグループ名と複数行の状態名、上へ張り出す自己ループを持つグループと、別グループと未所属状態がある。
- **WHEN** 初回に図の配置が完了する。
- **THEN** グループ名の末尾、所属状態の全領域と自己ループの経路が枠内に収まり、名前と状態は重ならず、別グループと未所属状態は枠外である。
- **AND** 枠とノード、矢印は図領域内へ収まり、長い内容を省略せず、状態定義表からの選択表示を除き、図からの状態選択とグループ選択はなく、操作ボタンはREQ-038の縮小、Reset、拡大とREQ-041の画像保存だけである。

#### Scenario: REQ-030-S04 - グループの除去で従来の図へ戻す

- **GIVEN** グループ枠と所属状態を表示している。
- **WHEN** 有効なままグループ宣言だけをすべて除去する。
- **THEN** 枠とグループ名は残らず、全状態の名前とカラー、定義順の配置は同じ内容のグループなし文書と一致する。

### Requirement: REQ-038 - 状態遷移図の倍率操作部

WHEN 状態遷移図を表示するとき、プレビューは、図の上部に左から`-`、`Reset`、`+`、REQ-041の`⇩`の4ボタンと現在の倍率の%表示を設け、縮小、等倍、拡大、図をエクスポートとして判別可能にしなければならない(SHALL)。\
拡大と縮小は現在の表示中心を維持し、設定した刻みと上下限に従って図だけの倍率を変える。\
マウスとTab、Enter、Spaceによる操作を受け付け、キーボードフォーカスを示し、明暗テーマで操作内容を読めるようにする。\
既存のドラッグとホイール操作を保ち、倍率表示は実際の図の倍率に追従する。\
図の準備前は操作部からの倍率操作を受け付けず、図がない場合は操作部を表示しない。\
状態と遷移の内容と配置、両表、選択状態を変えず、画像保存はREQ-041〜REQ-043に従い、図からの選択操作は追加しない。

#### Scenario: REQ-038-S01 - 3操作と実際の倍率を表示する

- **GIVEN** グループと自己ループを持つ図を表示している。
- **WHEN** 図の操作部を確認する。
- **THEN** 図の上部の倍率操作の3ボタンの表示文字は左から`-`、`Reset`、`+`で、読み上げ用の名前は`縮小`、`等倍`、`拡大`である。
- **AND** 実際の図の倍率を%で示し、拡大ボタンと倍率表示の間にREQ-041の保存ボタンが1つあり、状態とグループの選択の操作ボタンはない。

#### Scenario: REQ-038-S02 - 表示中心を維持して図だけを拡大縮小する

- **GIVEN** 上下限から離れた倍率で図を移動し、状態Aを選択している。
- **WHEN** 次のいずれかのボタンを押す。

  | ボタン | 期待する倍率 |
  | --- | --- |
  | + | 設定した刻みだけ増加 |
  | - | 設定した刻みだけ減少 |

- **THEN** 倍率は表の結果となり、表示領域の中心に対応する図上の位置は操作前と一致する。
- **AND** 図上のノードと枠の配置、遷移先と矢尻の方向、両表の内容と大きさ、Aの選択は変わらない。

#### Scenario: REQ-038-S03 - 設定した倍率の境界を超えない

- **GIVEN** 倍率が設定した上限または下限に近い図がある。
- **WHEN** 上限に向けて拡大を繰り返す、または下限に向けて縮小を繰り返す。
- **THEN** ボタンと既存のホイールのいずれでも倍率は設定した範囲内にあり、倍率表示は実際の倍率に対応し続ける。

#### Scenario: REQ-038-S04 - キーボードで3操作を起動する

- **GIVEN** 図の倍率操作の3ボタンへTabで到達できる。
- **WHEN** 縮小、等倍、拡大のいずれかにフォーカスを移し、EnterまたはSpaceで起動する。
- **THEN** フォーカスだけでは倍率を変えず、起動1回につき対応する倍率操作を1回行い、フォーカス位置を読み取れる。

#### Scenario: REQ-038-S05 - 既存の移動とホイールに倍率表示を追従させる

- **GIVEN** 図と操作部を表示している。
- **WHEN** 図をドラッグする、またはホイールで倍率を変える。
- **THEN** ドラッグでは表示位置だけが変わり、ホイールでは実際の倍率と%表示がそろって変わり、操作部のクリックをドラッグとして扱わない。

#### Scenario: REQ-038-S06 - 図がない場合は操作部を表示しない

- **GIVEN** 状態0件の有効な文書、または一度も正常に表示していない解析エラーの文書である。
- **WHEN** プレビューを表示する。
- **THEN** 既存の不足または解析エラーの案内を表示し、図の倍率操作部と倍率表示はない。

#### Scenario: REQ-038-S07 - 計測中の倍率操作を受け付けない

- **GIVEN** 図の状態名とグループ枠の計測が完了していない。
- **WHEN** 倍率のボタンを起動しようとする。
- **THEN** 倍率操作は行われず、準備完了後に現在の図を操作できる。

#### Scenario: REQ-038-S08 - 明暗テーマで操作とフォーカスを読み取る

- **GIVEN** 図と操作部を表示している。
- **WHEN** 明テーマまたは暗テーマでボタンへフォーカスを移す。
- **THEN** 操作部の文字と背景、フォーカス表示はテーマに沿い、倍率の3操作と保存操作、倍率を読み取れ、図の指定カラーと淡い矢印は保たれる。
