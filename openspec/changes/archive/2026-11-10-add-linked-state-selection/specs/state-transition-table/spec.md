# 差分仕様

## ADDED Requirements

### Requirement: REQ-037 - 選択した状態列全体の背景強調

WHILE REQ-034の状態選択がある間、状態遷移表は、選択した状態IDの列見出しと全イベント行の交点を薄い背景色で強調しなければならない(SHALL)。\
分岐なし、分岐付き、明示的ななし、未定義を問わず同じ列全体を対象とし、共通処理とすべての分岐を含める。\
状態の定義順とIDで対応付け、分類の段数と結合によって列をずらさず、同名の別状態列、イベント列と分類領域、他列にある選択状態への遷移先名は強調しない。\
見出しの指定カラー、未定義の赤文字、分岐の縦線と全セルの内容を保ち、選択を示す枠線を付けず、解除時は通常の背景へ戻す。\
表が表示されない場合は新しい列やセルを作らない。

#### Scenario: REQ-037-S01 - 同名状態でも選択IDの列だけを強調する

- **GIVEN** 状態の定義順はZ、A、Bで、AとBが同名であり、Bの列にもAへの遷移先名がある。
- **AND** Aの列には分岐なし、処理と遷移がともになし、未定義のセルがある。
- **WHEN** 状態定義表でAを選択する。
- **THEN** 中央のAの見出しと全セルだけの背景が変わり、ZとBの列、Bのセル内のAへの遷移先名は選択前の背景のままである。
- **AND** Aの指定カラーと赤文字の未定義、処理と遷移先は変わらず、解除すると見出しと全セルの背景が選択前へ戻る。

#### Scenario: REQ-037-S02 - 分類と分岐があっても交点全体を強調する

- **GIVEN** 分類なしと3段分類、共通祖先による行の結合、不足段の空欄、指定した分類見出しが混在する。
- **AND** 各状態の列には異なる内容があり、選択対象Aのセルには共通処理と処理なしや遷移なしを含む複数の分岐がある。
- **WHEN** 状態定義表でAを選択する。
- **THEN** Aの見出しとすべての交点で、共通処理から全分岐までのセル全体に選択背景が付き、分類の見出しと結合と空欄、イベント名と他状態の列は変わらない。
- **AND** 条件と処理と遷移先、なしと未定義、分類の結合範囲、元のIDの交点と分岐部分だけの縦線は選択前と一致する。

#### Scenario: REQ-037-S03 - イベントがない場合に選択用セルを作らない

- **GIVEN** 状態AとBはあるがイベントがない。
- **WHEN** 状態定義表でAを選択する。
- **THEN** Aの定義行とノードだけが選択表示され、状態遷移表はイベントがないことの案内のままであり、選択用の見出しやセルは作られない。
