# 実装と検証の記録

## テスト先行の確認

- 収集設定の更新前は、追加した`tests/webview/state-diagram.test.ts`が対象外となった。
- 収集設定の更新後は、既存129テストを保ったまま新しい10テストが実行され、未実装の変換で失敗した。
- 変換の実装後は10件が成功し、配置の追加テスト1件は未実装の配置で失敗した後に成功した。
- 図の実装前は、ノードと矢印のブラウザテスト16件が失敗し、実装後に成功した。
- 淡い配色、長い名前の計測後の配置、自己ループを含む表示範囲の追加3テストは、それぞれ未対応の表示で失敗した後に成功した。
- 図の計測前に親が描画完了を送る実装では、準備中の編集と古い完了に関するブラウザテスト2件が失敗した。\
  図の準備完了と最新通知の照合を実装し、実測を遅延させる条件でも成功した。

## 既存の実装によって最初から成功した確認

- REQ-017-S01、REQ-017-S02、REQ-017-S03、REQ-017-S04、REQ-017-S08のブラウザの追加13件は、D-01で3表示へ同じモデルを渡す実装により最初から成功した。
- 同じシナリオのExtensionの追加単体5件と実VS Codeの追加統合5件は、既存の対象URIの制御、正常モデルの保持と回復、診断の更新によって最初から成功した。
- REQ-017-S05の古い解析結果の拒否と、REQ-017-S06の再オープンに関する単体2件、ブラウザ2件、実VS Code統合2件は、既存の版番号の後始末と通知のsequenceによる制御を維持した状態で成功した。
- REQ-017-S03は、正常表示から参照エラーで保持し、その後に状態名、処理、遷移先を以前と異なる内容へ直す流れである。\
  ブラウザではノードと矢印、両方の表、エラー案内を確認し、単体と実VS Codeでは正常モデルと参照診断の消去、未保存の状態を確認した。

## 誤実装の検出

一時コピーで各誤実装を単独で適用し、対応するテストが失敗することを確認した。\
元の実装へ戻したコピーでは、対象の単体64件と図のブラウザ38件が成功し、元のソースとの一致を確認した。

| 誤実装 | 検出したシナリオ | 確認方法 |
| --- | --- | --- |
| 遷移なしを自己遷移へ置き換える | REQ-015-S02 | 単体テストが失敗 |
| 処理なしの矢印を消す | REQ-015-S02 | 単体テストが失敗 |
| イベントごとに同じ向きの矢印を重複させる | REQ-015-S03 | 単体テストが失敗 |
| 逆方向の遷移を同じペアへまとめる | REQ-015-S05 | 単体テストが失敗 |
| 古いURIやsequenceの準備完了を受け付ける | REQ-017-S05 | 単体テストが失敗 |
| 自己ループを長さ0の経路にする | REQ-015-S04 | ブラウザテストが失敗 |
| 淡い配色の設定を無視して線と矢尻へ前景色を使う | REQ-016-S01 | ブラウザテストが失敗 |
| 図だけ最初のモデルを使い続ける | REQ-017-S03 | ブラウザテストが失敗 |
| エラー修正後も以前の正常モデルを返す | REQ-017-S03 | 単体テストと実VS Codeの追加統合テストが失敗 |

回復の誤実装では、既存の状態遷移表の統合テストが先に失敗して後続の図のスイートを止めるため、コピーで図のスイート7件を単独実行した。\
追加した`diagramRepairAfterRetainedModel`だけが以前の名前、処理、遷移先との不一致で失敗し、残り6件は成功した。\
コピー内の限定実行は誤実装の確認のためであり、プロダクトのテストスイートは既存と追加分をすべて登録している。

## 描画完了の待機

図の計測を含む完了通知は、状態定義表の文字更新より後になる。\
既存のREQ-005-S05とREQ-003-S04のテストは、利用者の承認に基づき、完了通知の期待値を保ったまま`expect.poll`で待つ形へ変更した。\
新しい図の座標検証も同じ通知を待ってから行い、更新途中の位置や表示倍率を検証対象へ混入させない。\
完了通知を送らない誤実装をコピーへ適用すると、待機方法を変更した既存2件はどちらも失敗し、元の実装へ戻すと2件とも成功した。

## 矢尻の方向の回帰テスト

REQ-015-S01、REQ-015-S04、REQ-015-S05のブラウザテストへ、矢尻の方向と経路終端の進行方向の照合を追加した。\
実際のSVG輪郭の三角形から先端と底辺を識別し、形状の変換、マーカーの表示倍率と回転、画面座標への変換を反映した向きを比較する。\
通常遷移と自己ループに加え、相互遷移は両方向を確認する。

- 既存実装はSVGの自動回転を使っているため、補強した3テストは最初から成功した。
- 一時コピーで`orient`を180度に固定すると、3テストとも方向の不一致で失敗した。
- 自動回転を保って三角形の輪郭だけを逆向きにした誤実装でも、3テストとも失敗した。
